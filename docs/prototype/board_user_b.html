STEP 9b / 动态追问

AI 动态追问

追问不是随机的，而是基于「项目经历 + 岗位要求 + 当前回答」的共同上下文触发，用于强化薄弱维度的证据采集。

面试对话
面试官 · Mike请介绍一个你参与过的 AI 产品项目，以及你承担的工作。
你我负责该项目的产品设计，从 0 到 1 搭建对话框架，上线后留存提升 18%。
Follow-up Agent · 追问你刚才提到负责产品设计——当时是如何确定核心需求的？是否用数据验证过这个判断？
为什么问这个问题？
追问由三方上下文共同触发：
• 项目经历：命中「0→1 产品设计」
• 岗位要求：JD 强调数据驱动决策
• 当前回答：给出结果但缺少「如何验证」
Context（Resume + JD + Answer）→ 触发追问，聚焦「数据分析」薄弱维度的证据采集。
