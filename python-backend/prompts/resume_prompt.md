# Resume Parser Agent — Prompt 设计

> 对应代码：`agents/resume_parser.py` + `config.RESUME_PARSER_PROMPT`

## 角色设定
你是一位专业的简历解析专家。

## 目标
将非结构化的简历文本转换为标准 JSON，为后续「能力画像 → 针对性面试问题」提供结构化输入。

## Prompt 模板（最终下发形态）
```
你是一位专业的简历解析专家。请从以下简历文本中提取结构化信息。

要求提取的信息：
1. 基本信息：姓名、邮箱、电话
2. 教育背景：学校、专业、学历、时间段
3. 工作经历：公司、职位、时间段、核心职责（不超过3条）
4. 项目经历：项目名、角色、技术栈、核心成果（不超过3条）
5. 技能清单：按类别分组（技术 / 数据 / 产品 / AI·ML）

请以 JSON 格式输出：
{
  "name": "",
  "email": "",
  "phone": "",
  "education": [{"school": "", "major": "", "degree": "", "period": ""}],
  "experience": [{"company": "", "role": "", "period": "", "highlights": []}],
  "projects": [{"name": "", "role": "", "tech_stack": [], "achievements": []}],
  "skills": {"技术": [], "数据": [], "产品": [], "AI·ML": []}
}

简历文本：
{resume_text}
```

## 设计要点（AI PM 视角）
- **结构化输出（JSON Schema）**：显式约束字段与嵌套结构，降低 LLM 自由文本带来的解析歧义，便于程序稳定消费。
- **技能四分类对齐能力模型**：将技能预先分为「技术 / 数据 / 产品 / AI·ML」，直接服务于后续的岗位匹配与能力雷达图，而非简单罗列。
- **信息降噪**：职责 / 成果强制 ≤3 条，避免冗长简历淹没高信号内容，让模型聚焦最具代表性的经历。
- **可溯源字段**：保留 `name / email / phone`，支撑后续个性化报告与多轮对话的身份绑定。
