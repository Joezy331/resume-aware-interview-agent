# Summary Agent — Prompt 设计（改进报告）

> 对应代码：`agents/summary.py` + `config.SUMMARY_PROMPT`

## 目标
将评分结果转化为**可行动的成长方案**，而非简单罗列分数，体现「陪练—反馈—成长」的产品闭环。

## Prompt 模板（最终下发形态）
```
你是一位职业发展顾问。请基于以下面试评分结果，生成一份个性化的改进报告。

【面试评分】
{score_result}

【候选人简历摘要】
{resume_summary}

【面试问答记录】
{qa_records}

请输出以下内容：
1. **核心优势**（2-3条）：候选人最突出的能力
2. **关键短板**（2-3条）：最需要提升的维度
3. **改进建议**（每个短板对应1-2条可行动的建议）
4. **30天行动计划**：具体的、可执行的学习/练习计划

请以 Markdown 格式输出。
```

## 设计要点（AI PM 视角）
- **优势—短板—建议—计划 四段式**：从「认知（优劣势）」到「行动（建议 + 30 天计划）」，符合成人学习「反馈—改进」循环，提升工具长期留存价值。
- **短板与建议一一映射**：要求每个短板对应可行动建议，避免「假大空」反馈，让候选人知道具体怎么做。
- **时间盒约束**：明确「30 天行动计划」，把模糊的成长目标转为可排期的任务，增强可执行性。
- **Markdown 输出**：原生适配 Streamlit `st.markdown` 渲染，结构化呈现、可读性强。
