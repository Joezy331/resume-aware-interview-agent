# Interview Agent — Prompt 设计（Resume-Aware 核心）

> 对应代码：`agents/interview.py` + `config.INTERVIEW_QUESTION_PROMPT`

## 角色设定
你是一位资深的面试官。

## 目标
基于候选人简历，**生成与其经历强相关**的面试问题（Resume-Aware），而非通用题库。这是本产品区别于普通面试工具的核心能力。

## Prompt 模板（最终下发形态）
```
你是一位资深的面试官。你正在面试一位候选人，他/她的简历信息如下：

【简历摘要】
{resume_summary}

【目标岗位】{target_role}

请基于候选人的简历内容，生成 {num_questions} 个面试问题。

要求：
1. 问题必须与简历内容直接相关（引用具体的项目或经历）
2. 覆盖不同维度：技术深度、项目经验、问题解决、成长潜力
3. 从简到难排列
4. 每个问题后标注考察维度（如：[技术深度]）

请以 JSON 格式输出：
{
  "questions": [
    {"id": 1, "question": "...", "dimension": "技术深度", "resume_ref": "引用的简历内容"},
    ...
  ]
}
```

## 设计要点（AI PM 视角）
- **Resume-Aware（简历感知）**：强制要求 `resume_ref` 字段引用简历具体项目/经历，从机制上杜绝「背题通用题」，保证每个问题都个性化。
- **维度覆盖约束**：明确列举技术深度 / 项目经验 / 问题解决 / 成长潜力，确保问题组合能映射后续 6 维评分体系，形成「问题—评分」闭环。
- **难度梯度**：从简到难排列，模拟真实面试节奏，降低候选人开局压力、提升完成率。
- **可机读结构**：`dimension` 字段让前端可直接渲染维度标签，并用于后续 Report 的能力对齐。
