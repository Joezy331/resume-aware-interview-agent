# Follow-up Agent — Prompt 设计（动态追问）

> 对应代码：`agents/interview.py` + `config.FOLLOW_UP_PROMPT` + `should_follow_up()`

## 触发机制
`should_follow_up(answer, threshold=120)`：当候选人回答字数 `< 120` 时触发追问，避免对充分回答的无效打扰。

## 目标
对过简回答进行**针对性深挖**，把「敷衍式回答」转化为有价值的评估信号。

## Prompt 模板（最终下发形态）
```
候选人对上一个问题的回答过于简短（不足120字），需要追问以深入评估。

【原始问题】{original_question}
【候选人回答】{candidate_answer}
【考察维度】{dimension}

请生成一个追问，要求：
1. 针对回答中的薄弱点或模糊处深挖
2. 引导候选人提供更具体的细节（数据、方法、成果）
3. 语气友善但专业

直接输出追问内容，不要输出 JSON。
```

## 设计要点（AI PM 视角）
- **阈值触发 + 工程兜底**：用字数阈值（`120`）做轻量判断，无需额外 LLM 调用即可决定是否追问，兼顾体验与成本。
- **定点深挖而非换题**：追问锚定 `original_question` 与 `candidate_answer` 的薄弱点，引导给出「数据 / 方法 / 成果」三类具体信息，提升评估信噪比。
- **语气约束**：明确要求「友善但专业」，避免对抗式追问引发候选人抵触，保障陪练体验。
- **非结构化输出**：追问是单句对话文本，故不要求 JSON，降低生成失败概率、保证流式展示自然。
