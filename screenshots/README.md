## 如何生成

1. 直接用浏览器打开仓库根目录 `index.html`（无需安装、无需 Key）
2. 走通「简历 → 岗位推荐 → JD 解析 → 能力建模 → 面试 → 多面试官评分 → 报告 → 看板」流程
3. 对每个关键页面截图，按上表命名存入本目录
4. 提交前确认 `.gitignore` 未误伤 `.png`（当前 png 均纳入版本控制）

> 请勿在截图中包含真实个人信息（姓名 / 手机号 / 邮箱密码 / 身份证）。演示请使用**虚拟简历**。
