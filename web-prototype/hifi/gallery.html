USER 用户端 · 17 个功能页 从「首页 Dashboard」到「能力成长」，逐页对应低保真用户端
01 首页 Dashboard USER
登录总览，进度 / 最近面试 / 下一站建议 / 能力雷达
02 上传简历 USER
拖拽或选择简历文件，分阶段实时解析进度动画
03 简历解析 USER
Resume Parser 抽取教育 / 项目 / 技能，生成能力画像
04 岗位推荐 USER
Job Match Agent 依据简历向量匹配 11 类岗位并给出匹配分
05 JD 分析 USER
粘贴 / 截图目标公司 JD，解析关键词与简历命中率
06 能力模型 USER
由简历 + JD 生成岗位能力树与考察重点
07 目标岗位 USER
确认本次面试针对哪个岗位与哪套能力模型
08 动态权重 USER
评分权重随岗位类型动态调整（5 套模板可切换重排）
09 面试难度 USER
轻量 / 标准 / 挑战 等档位可选，影响题量与追问深度
10 AI 面试 USER
基于简历 + JD 动态生成问题，实时观察与录音态
11 动态追问 USER
Follow-up Agent 基于项目经历 + 岗位要求 + 当前回答触发追问
12 多 Agent 评价 USER
HR / 业务 / 专业 / Leader / Chief 五方独立评分并仲裁冲突
13 面试结束 USER
问题数 / 时长 / 维度统计，引导查看报告与成长计划
14 评分报告 USER
六维评分 + 录用概率预测 + Top3 优势 / 待提升
15 面试记录 USER
本机持久化历史面试，时间轴 / 得分趋势 / 空态与删除态
16 API / OCR 状态 USER
外接大模型与百度 OCR 的调用态、失败兜底与配置来源
17 能力成长 USER
短板分析 → 30/60/90 天成长计划 → 再次练习闭环
ADMIN 管理员端 · 9 个功能页 运营概览 / 用户 / 面试 / 评分 / 岗位 / Agent / 日志 / 系统
01 Overview 数据看板 ADMIN
登录态 + 运营 KPI、转化漏斗与评分 / 岗位分布
02 Users 用户数据 ADMIN
用户画像、目标岗位与面试完成情况分布
03 Interviews 面试数据 ADMIN
每一次面试的过程、评分与完成率记录
04 Scores 评分数据 ADMIN
六维均值与评分区间分布，用于校准动态权重
05 Jobs 岗位数据 ADMIN
11 类岗位的匹配聚合、平均匹配与发展路径
06 Agents 运行监控 ADMIN
13 个 Agent 的运行状态、调用量与成功率
07 Agent Detail 详情 ADMIN
单个 Agent 的 Input → Process → Output 与延迟 / 异常
08 Logs 运行日志 ADMIN
运行日志 / 系统情况，错误兜底与恢复状态
09 System 系统状态 ADMIN
13-Agent 架构图、API 可用率 / 队列 / 存储
